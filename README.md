# CITS5508_MachineLearning

Coursework repository for CITS5508 (Machine Learning), including weekly labs, assignments, and reference material.

## Repository layout

- `lab1` - `lab7`: weekly lab notebooks and supporting files
- `asst_1`, `asst_2`: assignment notebooks, briefs, and datasets
- `datacamp`: DataCamp practice notebooks
- `game`: project/game-related machine learning work
- `handson-ml3`: notes and exercises from *Hands-On Machine Learning*
- `cits5508-2026.yml`: Conda environment definition

## Getting started

1. Create the Conda environment:
   `conda env create -f cits5508-2026.yml`
2. Activate the environment:
   `conda activate cits5508-2026`
3. Open notebooks from any lab or assignment folder in Jupyter.

## Notes

- Most work in this repository is notebook-based (`.ipynb`).
- PDF files in lab and assignment folders contain the task specifications.
